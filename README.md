# Operações Matemáticas em Python

Este é o meu **primeiro projeto em Python**! Ele consiste em uma calculadora simples baseada em terminal que realiza operações matemáticas fundamentais utilizando conceitos de Programação Orientada a Objetos (POO).

## Estrutura do Projeto

O projeto está organizado com os seguintes arquivos:

*   `main.py`: O ponto de entrada do aplicativo que inicia a execução.
*   `menu.py`: Gerencia a interface de usuário no terminal e a escolha das operações.
*   `OperacaoMatematica.py`: Classe ou módulo base para as operações.
*   `Soma.py`: Contém a lógica para a operação de adição.
*   `Subtracao.py`: Contém a lógica para a operação de subtração.
*   `Multiplicacao.py`: Contém a lógica para a operação de multiplicação.
*   `Divisao.py`: Contém a lógica para a operação de divisão.

## Tecnologias Utilizadas

*   **Python 3**

## Como Executar o Projeto

### Pré-requisitos
Você precisa ter o Python instalado em seu computador. Caso não tenha, faça o download em [python.org](https://python.org).

### Passo a Passo

1. **Baixe ou clone este repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Navegue até a pasta do projeto:**
   ```bash
   cd nome-do-seu-repositorio
   ```

3. **Execute o arquivo principal:**
   ```bash
   python main.py
   ```
